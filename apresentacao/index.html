🔑 Autenticação Rápida por PIN

Para facilitar a operação na moto pelo celular, o entregador não precisa digitar senhas complexas: o sistema calcula o PIN com base nos 4 últimos dígitos do WhatsApp cadastrado.

Exemplo: Celular (45) 99876-4321 ➔ PIN de Acesso: 4321

📍 Google Maps com 1 Toque

Ao aceitar a entrega, o botão "Abrir Rota no Google Maps" gera imediatamente o deep-link com o endereço completo, complemento e cidade do cliente, abrindo o GPS nativo sem precisar digitar.

Link automático: google.com/maps/dir/?api=1&destination=...

Engenharia de Concorrência

A Solução Definitiva para a Corrida do Motoboy

Em pizzarias e hamburguerias, quando um pedido fica pronto, dezenas de entregadores apertam "Aceitar" na mesma fração de segundo. Se o sistema não tiver proteção atômica, dois motoboys vão até o endereço do mesmo cliente.

UPDATE pedidos
SET motoboy_id = ?, status = 'em_entrega', aceito_em = datetime('now')
WHERE id = ? AND motoboy_id IS NULL AND status = 'pronto'
O 1º Motoboy no milissegundo: Recebe HTTP 200, a corrida é fixada para ele e removida instantaneamente das telas dos outros via WebSocket.
Os outros 9 Motoboys simultâneos: O banco retorna changes = 0 e a API devolve HTTP 409 Conflict avisando que a corrida acabou de ser pega.
